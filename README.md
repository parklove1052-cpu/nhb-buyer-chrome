# NHB 바이어 수집기 (크롬 + Playwright)

API 키 없이 **크롬으로 구글 지도·링크드인을 검색**해서 해외 바이어 후보(업체명·주소·전화·웹사이트)를 모으고, 주간 보고서를 만듭니다.

## 처음 쓰는 PC — 이 순서대로만 하세요

**준비물:** 윈도우 PC, 인터넷, 링크드인 계정 1개 (API 키는 필요 없습니다)

### 1단계. 받기
명령 프롬프트(cmd)에서:
```
git clone https://github.com/parklove1052-cpu/nhb-buyer-chrome.git
```
git 이 없으면 GitHub 화면의 **Code → Download ZIP** 으로 받아 압축을 풀어도 됩니다.

### 2단계. 설치 — `install.cmd` 더블클릭
아래 4줄이 차례로 뜨고 `설치 끝` 이 나오면 성공입니다. 아무 키나 누르면 창이 닫힙니다 (처음엔 브라우저를 받느라 몇 분 걸립니다).
```
[1/4] 파이썬: ...                      ← 없으면 자동 설치
[2/4] Playwright 준비 완료
[3/4] 브라우저 설치 확인 중...
[4/4] 매주 월요일 09:00 자동 실행 등록 완료
```

### 3단계. 첫 실행 — `run.cmd` 더블클릭 (이때만 사람이 필요)
1. 크롬 창이 뜨고 **구글 지도 수집**이 먼저 알아서 돌아갑니다. 건드리지 마세요.
2. 링크드인 차례가 되면 **로그인 화면**이 뜹니다 → 그 창에서 **직접 로그인**하세요.
   - 보안 인증(로봇 확인·문자 인증) 화면이 떠도 그 창에서 풀면 됩니다.
   - **5분 안에** 끝내면 자동으로 이어서 수집합니다. 넘기면 링크드인만 건너뛰고 끝납니다 (다시 `run.cmd`).
3. 크롬 창이 닫히고 검은 창에 `끝 (코드 0)` 이 뜨면 완료 (검은 창은 20초 뒤 저절로 닫힙니다).

### 4단계. 끝 — 이후는 자동
로그인은 이 폴더의 `profile/` 에 저장됩니다. **다음 주부터는 월요일 09:00 에 아무도 없이 자동으로** 수집·보고합니다 (PC만 켜져 있으면 됩니다).

## 잘 됐는지 확인

- `data\leads.csv` 를 엑셀로 열어 `source` 칸에 **maps** 와 **linkedin** 이 둘 다 있으면 정상.
- 링크드인이 하나도 없으면 `logs\run.log` 를 열어 보세요:

| 로그에 뜬 말 | 뜻 / 할 일 |
|---|---|
| `링크드인 로그인 필요` | `config.json` 의 `headless` 가 `true` 입니다 → `false` 로 바꾸고 `run.cmd` 다시 |
| `로그인 대기 시간 초과` | 5분 안에 로그인을 못 했습니다 → `run.cmd` 다시 |
| `링크드인 결과가 안 떴습니다` | 로그인은 됐는데 결과를 못 읽었습니다 → `logs\run.log` 를 관리자에게 보내 주세요 |
| `검색 결과가 안 떴습니다` | 구글 지도 문제 (인터넷 확인) → 잠시 뒤 다시 |
| `설치 실패` | 설치 창의 메시지를 캡처해 관리자에게 보내 주세요 |

- 로그인이 풀렸으면(비밀번호 변경 등) `run.cmd` 를 한 번 더블클릭해 다시 로그인하면 됩니다.
- 다른 계정으로 바꾸려면 `profile` 폴더를 지우고 `run.cmd`.
- 자동 실행을 끄려면: cmd 에서 `schtasks /delete /tn NHB-Buyer-Collect /f`

## 결과 위치

| 파일 | 내용 |
|---|---|
| `data/leads.csv` | 모은 업체 전체 (엑셀로 열림, 중복 자동 제외) |
| `reports/report_날짜.md` | 주간 보고 (전체 / 최근 7일 새 후보) |
| `logs/run.log` | 실행 기록 |

`data/` `reports/` `profile/` 은 깃에 올라가지 않습니다 (바이어 자료 보호).

## 설정 — `config.json`

- `queries`: 구글 지도 검색어 (국가·도시·업종 바꾸면 다른 시장)
- `linkedin_queries`: 링크드인 회사 검색어 (검색어당 1페이지, 검색 사이 5~10초 쉼)
- `linkedin_max_per_query`: 링크드인 검색어당 최대 회사 수
- `max_per_query`: 검색어당 최대 업체 수
- `headless`: `false` = 크롬 창이 보이게, `true` = 창 없이

## 명령

```
run.cmd            수집 + 보고
run.cmd collect    수집만
run.cmd report     보고만
```

설치된 크롬이 있으면 그걸 쓰고, 없으면 Playwright 크롬을 씁니다. 크롬 로그인 상태는 `profile/` 에 저장돼 다음 실행에도 유지됩니다.

## 주의

- 구글 지도 결과는 "후보"일 뿐 수입 실적이 아닙니다.
- 비밀번호는 코드·파일 어디에도 넣지 않습니다. 로그인은 사람이 크롬 창에서 직접 하고, 크롬이 `profile/` 에 기억합니다.
- 링크드인은 자동 수집을 약관으로 막고 있어, 너무 많이 돌리면 계정이 제한될 수 있습니다. 검색어 수를 적게 유지하세요.
- 자동 실행은 그 시간에 PC가 켜져 있어야 합니다.
